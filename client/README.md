# 实况魁地奇 Godot 本地原型

在 `Quidditch` 目录用 PowerShell 运行 `.\play-local.ps1 -TeamSize 7`。它会编译并启动 Scala 后端，打开 Godot 游戏窗口，并预选七人制人机对战。需要在 `PATH` 中提供 JDK 21，首次构建会从 Maven Central 下载依赖。脚本默认使用本机 `E:\Godot` 中的 Godot。如路径不同，传入 `-GodotExe`。关闭游戏窗口会停止该次启动的后端。

首次打开游戏时，填写账号和密码，点击「注册账号」，然后点击「登录」。账号保存在原有的 SQLite 数据库中。登录后选择对战模式和格兰芬多首发球员卡，再点击「开始比赛」。会话有效期为 8 小时，重启后端后需要重新登录。

运行 `.\play-local.ps1 -Watch` 可预选观战模式。绿队和蓝队由同一套 AI 操控，球员属性来自各自的球员卡。侧上方镜头会跟随双方和鬼飞球。用 `.\play-local.ps1 -Watch -Smoke` 验证观战模式。

运行 `.\play-local.ps1 -TeamSize 2` 可预选两人队伍模式，可与 `-Watch` 一起用。格兰芬多为哈利和罗恩，斯莱特林为德拉科和克拉布。**R** 传给队友，**Tab** 切换操控，**E** 接球。镜头跟随选中的角色，其名字显示为金色。未选中的队友由电脑操控。

| 操作 | 键位 |
| --- | --- |
| 开赛 | Enter |
| 结束比赛并返回大厅 | Esc |
| 相对飞行朝向前进、倒飞和横移 | WASD |
| 向左、向右调整飞行朝向 | Z、X |
| 上升和下降 | 空格、C |
| 冲刺 | Shift |
| 接鬼飞球 | E |
| 肩后瞄准 | 持球时按住右键，移动鼠标转向和调整仰角 |
| 键盘微调 | ← → 左右转，↑ ↓ 抬高或压低，Q 回到球员朝向 |
| 投球 | F，或瞄准时按左键 |
| 冲撞、拉拽、护球 | V、G、B |

橙色球是鬼飞球。宽视角跟随飞行朝向，瞄准时切到带准星的肩后镜头。两种视角下，WASD 都以 Z/X 调整的飞行朝向为基准。球员模型在倒飞或横移时平滑转向实际移动方向，停下后回正。绿色箭头表示预计出手瞬间的轨迹切线，会随手动瞄准和球员当前速度偏转。投远球时需要抬高方向，为下坠留余量。后端仍会结算出手偏差、碰撞、得分、犯规和计时，Godot 插值显示位置。对战或观战时，开赛者按 Esc 可结束比赛，回到大厅后可以直接开新一场。

引擎项目入口为 `project.godot`。手动启动后端时可运行 `sbt "run 8080 cpu"`，再运行 Godot 项目。客户端默认连接 `127.0.0.1:8080`，也可通过 `QUIDDITCH_BACKEND_URL` 覆盖。使用 `.\play-local.ps1 -Smoke` 可以在后台验证实际 Godot 客户端与 Scala 后端的开赛、飞行、接球和投球得分链路。

球场来自本地 `Quidditch_Pitch.blend`，骑手客户端资产取自 `Quidditch_Harry_Takeoff.blend` 的飞行关键帧。角色模型由 RRB STUDIOS 上传，模型页标注 CC BY 4.0。本地原型复用了飞行姿态，完整拿帚和起飞动画在 Blender 源文件内。 [角色模型来源](https://sketchfab.com/3d-models/harry-potter-rigged-character-250a590d181e4f6cb0aec4a0c55e293c)
